# Quality & Standards at Saudia Airlines

**A quality and standards project focused on reducing frequent flight delays at Saudia Airlines.**

</div>

---

## 📌 Project Overview

This project focuses on improving quality management and software systems at Saudia Airlines to address frequent flight delays through international standards, root-cause analysis, performance monitoring, and continuous improvement.

## 🎯 Objectives

- Improve software quality and management
- Apply international quality and aviation standards
- Identify the root causes of frequent flight delays
- Improve operational efficiency
- Enhance customer and employee experience
- Support continuous improvement

## 🔍 Fishbone Analysis

The Fishbone Diagram was used to analyze the main causes of frequent flight delays across six categories:

- **Manpower**
- **Methods**
- **Machines**
- **Materials**
- **Measurement**
- **Milieu**

## 📋 Standards

The project discusses the application of:

- ISO 9001
- ISO 27001
- IATA / IOSA
- GACA
- GDPR
- WCAG

## 📊 Key Quality Indicators

- On-time performance
- Passenger satisfaction
- System uptime
- Maintenance completion
- Data security
- Operational efficiency

## 🚀 Implementation

The proposed implementation includes:

1. Requirements analysis
2. Standards customization
3. Information security implementation
4. Flight scheduling optimization
5. Accessibility and privacy compliance
6. Performance monitoring
7. Continuous improvement
